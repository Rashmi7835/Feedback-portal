# Cloudsoftera Feedback Portal

The **Cloudsoftera Feedback Portal** is a web-based application designed to simplify feedback collection, survey management, and reporting. It helps organizations collect user responses, monitor customer satisfaction through Net Promoter Score (NPS), and generate reports for data-driven decision-making.

## Key Features
- Feedback collection and management
- Survey and questionnaire management
- NPS tracking and analysis
- Report generation and data analysis
- Excel-based reporting and pivot report support
- Responsive and user-friendly interface
- Backend services powered by Spring Boot

## Technology Stack
- **Backend:** Java, Spring Boot
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Database:** MySQL (if configured)
- **Build Tool:** Maven

## Purpose
To provide organizations with a centralized platform for gathering feedback, measuring satisfaction, analyzing responses, and generating actionable insights.
